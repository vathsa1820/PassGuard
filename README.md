# PassGuard 🛡️

PassGuard is an advanced password strength, pattern detection, entropy analysis, and security auditing library and application suite.

## Project Structure

- **`client/`**: React + TypeScript frontend application and UI component library.
- **`server/`**: Node.js + Express backend API service.
- **`docs/`**: Specifications, system design, PRD, and API reference.
- **`examples/`**: Integration examples for React, Next.js, and HTML.

## Getting Started

```bash
# Install dependencies
npm install

# Start development environment
npm run dev
```
