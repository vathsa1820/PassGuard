# PassGuard Design System - Typography

Designed for maximum legibility in dense form layouts across web and mobile viewports.

## 1. Font Family
- **Primary Font Family**: `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **Monospace Font (Code/Entropy)**: `"JetBrains Mono", "Fira Code", ui-monospace, SFMono-Regular, monospace`

## 2. Type Scale & Hierarchy

| Role | Font Size | Line Height | Weight | Tracking (Letter Spacing) | Usage |
|------|-----------|-------------|--------|--------------------------|-------|
| **Heading 1** | 20px (1.25rem) | 28px (1.4) | 600 (SemiBold) | -0.015em | Component titles / modal headers |
| **Heading 2** | 16px (1.0rem) | 24px (1.5) | 600 (SemiBold) | -0.011em | Card section headers |
| **Body Standard** | 14px (0.875rem) | 20px (1.43) | 400 (Regular) | 0em | Main input values, descriptions |
| **Body Medium** | 14px (0.875rem) | 20px (1.43) | 500 (Medium) | 0em | Interactive labels, list item text |
| **Caption / Helper** | 12px (0.75rem) | 16px (1.33) | 400 (Regular) | 0.01em | Subtext, strength labels, entropy metrics |
| **Badge / Micro** | 11px (0.6875rem) | 14px (1.27) | 600 (SemiBold) | 0.02em | Status pill text, uppercase tags |

## 3. Font Weight Tokens
- **Regular**: 400
- **Medium**: 500
- **SemiBold**: 600
