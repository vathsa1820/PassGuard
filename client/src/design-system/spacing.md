# PassGuard Design System - Spacing System

Built on an **8-Point Spacing Grid** for predictable mathematical rhythm and effortless alignment.

## Spacing Scale

| Token Name | Value (px) | Value (rem) | Primary Application |
|------------|------------|-------------|---------------------|
| `space-1` | 4px | 0.25rem | Micro inline gaps, icon-to-text spacing |
| `space-2` | 8px | 0.5rem | Tight component padding, vertical stack gap |
| `space-3` | 12px | 0.75rem | Input internal padding (vertical), medium list gap |
| `space-4` | 16px | 1.0rem | Input internal padding (horizontal), standard gap |
| `space-6` | 24px | 1.5rem | Card internal padding, block element spacing |
| `space-8` | 32px | 2.0rem | Section container margins, major stack gap |
| `space-12` | 48px | 3.0rem | Outer container boundaries |
