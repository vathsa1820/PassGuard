# PassGuard Design System - Border Radius

Clean, geometric, and modern border radius tokens aligned with modern component libraries (shadcn/ui & Tailwind).

## Radius Tokens

| Component Type | Token | Radius Value | Design Intent |
|----------------|-------|--------------|---------------|
| **Inputs** | `radius-md` | 6px (`0.375rem`) | Clean form field edges matching standard SaaS input fields |
| **Buttons** | `radius-md` | 6px (`0.375rem`) | Cohesive input-and-button pairing |
| **Badges / Status Pills** | `radius-full` | 9999px | Distinct pill shape for quick visual scan |
| **Cards / Containers** | `radius-lg` | 8px (`0.5rem`) / 12px (`0.75rem`) | Subtle framing without feeling oversized |
| **Tooltips / Popovers** | `radius-md` | 6px (`0.375rem`) | Sharp floating overlay aesthetics |
