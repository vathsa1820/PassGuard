# PassGuard Design System - Iconography

## Recommended Icon Library
- **Library**: `lucide-react` (Clean, consistent 2px stroke grid, zero-dependency tree-shakeable SVG icons).

## Sizing & Stroke Standards

| Token | Size | Stroke Width | Primary Usage |
|-------|------|--------------|---------------|
| **Icon Small** | 14px x 14px | 2px | Requirement checklist icons, inline status |
| **Icon Medium** | 16px x 16px | 2px | Input prefix/suffix icons, visibility toggle |
| **Icon Large** | 20px x 20px | 2px | Card header status icons, warning badges |

## Standard Icon Mapping
- **Eye / EyeOff**: Password visibility toggle
- **Check**: Requirement met
- **X**: Requirement failed
- **ShieldCheck**: Strong password score indicator
- **AlertCircle / AlertTriangle**: Password reuse / sequential pattern warnings
- **Info**: Contextual tooltip details
