# PassGuard Design System - Component Library Specifications

Reusable, headless-friendly UI components tailored for seamless integration into host applications.

## Component Inventory

1. **`<PasswordInput />`**
   - Controlled password input with visibility toggle, focus ring handling, and optional entropy meter suffix.

2. **`<PasswordStrengthBar />`**
   - Multi-segment (4 bars) or continuous progress bar indicating score (0 to 4).

3. **`<PasswordScoreBadge />`**
   - Accessible status pill showing textual evaluation ("Very Weak", "Weak", "Fair", "Good", "Strong").

4. **`<RequirementChecklist />`**
   - Dynamic list tracking character count, uppercase, lowercase, numbers, and special symbols.

5. **`<SuggestionCard />`**
   - Contextual alert box providing actionable feedback (e.g., "Avoid sequential numbers like '1234'").

6. **`<ReuseWarning />`**
   - Warning banner alerting users to previously compromised or reused passwords.
